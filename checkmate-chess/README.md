# Checkmate Chess

A modern, mobile-first chess app project by Suminuj.

## Planned features
- Local two-player mode
- Play against computer
- Legal chess moves, castling, en passant and promotion
- Undo, restart and move history
- Offline-first gameplay
- Android APK built with GitHub Actions

## Development
The project is being developed phone-first. See the app source and Android build workflow as they are added.
